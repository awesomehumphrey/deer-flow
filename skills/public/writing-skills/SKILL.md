# Writing Skills

## Overview

This skill provides techniques for effective non-fiction writing. Use it when drafting chapters, refining prose, or improving clarity and engagement.

## When to Use This Skill

- Drafting chapters or sections
- Revising for clarity and flow
- Improving sentence-level prose
- Finding the right voice and tone
- Making technical content accessible

## Core Writing Principles

### 1. Clarity First

- **One idea per paragraph**: Don't overload
- **Active voice**: "The study found" not "It was found by the study"
- **Concrete over abstract**: Show, don't tell
- **Cut ruthlessly**: If it doesn't serve the argument, delete it

### 2. Engagement Techniques

#### Opening Hooks
- Start with a scene or moment
- Pose a provocative question
- Present a surprising fact
- Introduce a character facing a problem

#### Maintaining Interest
- Vary sentence length (short punchy sentences create emphasis)
- Use specific details and examples
- Create mini-cliffhangers between sections
- Return to recurring themes or characters

### 3. Explaining Complex Ideas

The **ADEPT Method**:
- **A**nalogy: Compare to something familiar
- **D**iagram: Visual representation
- **E**xample: Concrete instance
- **P**lain language: No jargon
- **T**echnical term: Introduce proper terminology last

Example:
> "Think of machine learning like teaching a child to recognize dogs. You don't give them a rulebook defining 'dog.' Instead, you show them hundreds of pictures—this is a dog, this isn't—until they develop an intuition. That process of learning from examples is what computer scientists call 'training a model.'"

### 4. Voice and Tone

For academic-but-accessible writing (Brian Christian style):
- Curious, not lecturing
- Humble about uncertainty
- Enthusiastic about ideas
- Respectful of the reader's intelligence
- Personal where appropriate (use "I" when sharing your journey)

### 5. Paragraph Structure

**The ICE Method**:
- **I**dea: State the main point
- **C**ontent: Evidence, examples, elaboration
- **E**xit: Transition or implication

## Revision Checklist

- [ ] Does every paragraph have a clear purpose?
- [ ] Are there unnecessary words to cut?
- [ ] Is jargon explained or eliminated?
- [ ] Do transitions guide the reader?
- [ ] Is the voice consistent?
- [ ] Would a smart non-expert understand this?

## Common Fixes

| Problem | Solution |
|---------|----------|
| Too abstract | Add a concrete example |
| Too long | Split into two paragraphs |
| Boring opening | Start with action or question |
| Passive voice | Identify the actor, make them the subject |
| Jargon-heavy | Explain or replace with plain language |
| Disconnected | Add transition sentences |
