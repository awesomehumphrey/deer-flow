# Document Co-Authoring Skill

## Overview

This skill facilitates collaborative writing, helping you iterate on drafts, integrate feedback, and maintain consistency across a long document.

## When to Use This Skill

- Iterating on draft chapters with feedback
- Integrating content from multiple sources
- Maintaining voice consistency across sections
- Responding to editorial comments
- Merging contributions from different writing sessions

## Co-Authoring Workflow

### 1. Draft Review Process

When reviewing a draft:

1. **First Pass - Structure**
   - Does the argument flow logically?
   - Are sections in the right order?
   - Is anything missing or redundant?

2. **Second Pass - Content**
   - Are claims supported by evidence?
   - Are examples effective?
   - Is technical content accurate?

3. **Third Pass - Prose**
   - Is the writing clear and engaging?
   - Is voice consistent?
   - Are there awkward sentences?

### 2. Feedback Integration

When receiving feedback:

```
1. Categorize feedback:
   - Must fix (factual errors, logical flaws)
   - Should fix (clarity issues, missing context)
   - Could fix (style preferences, optional improvements)

2. Address in order of importance

3. Preserve what works while fixing what doesn't
```

### 3. Source Integration

When weaving multiple sources into prose:

- **Summarize** for background context
- **Paraphrase** for supporting points
- **Quote directly** only for memorable or precise language
- **Cite** everything (maintain a running reference list)

Template for integrating a source:
> [Context sentence]. According to [Author] ([Year]), [key finding or claim]. This suggests that [your interpretation]. [Transition to next point].

### 4. Consistency Maintenance

Track these elements across the document:

| Element | What to Track |
|---------|---------------|
| Terminology | Use the same term for the same concept |
| Voice | First person? Third person? Formal? Conversational? |
| Tense | Past for completed research, present for ongoing truths |
| Formatting | Heading styles, citation format, list styles |
| Characters | If following researchers, keep details consistent |

### 5. Version Management

For long projects:
- Save versions at major milestones (draft-v1, draft-v2, etc.)
- Keep a changelog of major revisions
- Don't delete—move cut content to a "scraps" file (you may need it later)

## Iteration Prompts

Use these to request specific help:

- "Review this section for logical flow"
- "Suggest stronger transitions between these paragraphs"
- "Simplify this technical explanation for a general audience"
- "Integrate these three sources into a coherent paragraph"
- "Check this chapter for consistency with Chapter 1"
- "Strengthen the argument in paragraph 3"

## Output Conventions

When co-authoring, clearly mark:
- `[SUGGESTION]` - Optional improvement
- `[QUESTION]` - Needs author clarification
- `[ISSUE]` - Problem that must be addressed
- `[NOTE]` - Context for the author, not for final text
