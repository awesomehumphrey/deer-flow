# Writing Plans Skill

## Overview

This skill helps you plan and structure long-form writing projects. Use it before starting any substantial writing to ensure clear organization and logical flow.

## When to Use This Skill

- Planning a book, thesis, or long report
- Creating chapter outlines
- Structuring complex arguments across multiple sections
- Breaking down a large writing project into manageable pieces
- Establishing narrative arc for non-fiction

## Planning Methodology

### Phase 1: Project Scoping

1. **Define the Core Thesis**: What is the single most important argument or message?
2. **Identify the Audience**: Who will read this? What do they already know?
3. **Determine Scope**: What's in and what's out?
4. **Set Constraints**: Length, format, deadline, style requirements

### Phase 2: Structure Design

#### For Argumentative Non-Fiction
```
1. Hook / Problem Statement
2. Context / Background
3. Main Argument (broken into sub-arguments)
4. Evidence & Examples (for each sub-argument)
5. Counterarguments & Rebuttals
6. Implications / So What?
7. Call to Action / Conclusion
```

#### For Narrative Non-Fiction (Brian Christian style)
```
1. Opening Scene / Character Introduction
2. The Question or Problem
3. Historical Context / How We Got Here
4. The Journey (researchers, discoveries, setbacks)
5. Technical Deep Dives (made accessible)
6. Stakes and Implications
7. Where We Go From Here
```

### Phase 3: Chapter Breakdown

For each chapter, define:
- **Purpose**: What does this chapter accomplish?
- **Key Points**: 3-5 main ideas
- **Evidence Needed**: What sources, data, examples?
- **Transitions**: How does it connect to previous/next chapters?
- **Estimated Length**: Word count target

### Phase 4: Writing Schedule

Create a realistic timeline:
- Research phase
- First draft (chapter by chapter)
- Revision rounds
- External feedback
- Final polish

## Output Format

When using this skill, produce:

1. **Project Brief** (1 page): Thesis, audience, scope
2. **Chapter Outline** (2-3 pages): Structure with key points per chapter
3. **Research Checklist**: What sources are needed
4. **Writing Schedule**: Timeline with milestones

## Tips

- Start with the ending: What should the reader take away?
- Each chapter should be able to stand alone while contributing to the whole
- Plan for 20% more content than needed (you'll cut during editing)
- Build in buffer time for unexpected research needs
