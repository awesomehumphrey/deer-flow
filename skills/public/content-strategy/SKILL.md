# Content Strategy Skill

## Overview

This skill helps you think strategically about your content—what to say, in what order, and how to make your argument compelling across a long work.

## When to Use This Skill

- Deciding what to include or exclude
- Ordering chapters or sections for maximum impact
- Identifying your key messages
- Ensuring each part serves the whole
- Analyzing what your audience needs

## Strategic Framework

### 1. Message Hierarchy

Define three levels:

```
CORE MESSAGE (1 sentence)
└── What's the single most important takeaway?

KEY THEMES (3-5 points)
└── What are the main supporting ideas?

SUPPORTING EVIDENCE (per theme)
└── What proves each point?
```

Example for "Human Values in Software":
```
CORE: Software systems routinely violate human values, and we can detect and prevent this.

THEMES:
1. Values violations are systematic, not accidental
2. Users suffer real harm from these violations
3. Developers face structural pressures that cause violations
4. Automated detection is possible and effective
5. A value-aligned future is achievable

EVIDENCE: Research papers, case studies, developer surveys, detection results
```

### 3. Chapter Sequencing Strategies

**The Problem-Solution Arc**:
1. Establish the problem (make reader feel the pain)
2. Failed solutions (what's been tried)
3. New approach (your contribution)
4. Evidence it works
5. Implications and future

**The Journey Arc** (narrative non-fiction):
1. Hook with a compelling character/scene
2. The question that drives the story
3. Historical context
4. The investigation (following researchers)
5. Discoveries and setbacks
6. Resolution and implications

**The Layer Cake** (building complexity):
1. Simple version of the idea
2. Add nuance and exceptions
3. Technical deep dive
4. Real-world applications
5. Future directions

### 4. Strategic Questions for Each Chapter

Before writing, answer:
- **Why this chapter?** What role does it play?
- **Why here?** Why this position in the sequence?
- **What's the one thing?** If readers remember only one thing, what is it?
- **What's the hook?** Why will they keep reading?
- **What's the bridge?** How does it connect to what comes next?

### 5. Content Gap Analysis

Review your plan for:
- **Missing evidence**: Claims without support
- **Missing context**: Assumed knowledge not provided
- **Missing stakes**: Why should readers care?
- **Missing voices**: Perspectives not represented
- **Missing transitions**: Logical leaps between sections

## Output: Content Strategy Document

When using this skill, produce:

1. **Core Message Statement** (1-2 sentences)
2. **Theme Breakdown** (3-5 themes with evidence mapped)
3. **Chapter Sequence Rationale** (why this order)
4. **Audience Profile** (who and what they need)
5. **Gap Analysis** (what's missing)
